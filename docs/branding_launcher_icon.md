# Launcher icon and splash

Logo: "B. Core Ring". The icon uses the dark variant (pale disc, grey ring, navy core, white bolt) on a deep-navy #0A1F4D tile, because the light variant's navy disc would vanish on navy.

- Legacy icon: 22% rounded tile. Adaptive icon: navy background colour plus a foreground with the logo inside the 66 dp safe zone, and a white ring-and-bolt monochrome layer for Android 13 themed icons.
- Splash: Android 12+ uses `values-v31` / `values-night-v31` (navy background, `splash_icon`); older versions use `drawable/launch_background.xml`.
- Everything is generated by `tool/make_app_icons.py` (see [tools.md](tools.md)). Preview: `docs/branding/store/icon-preview.png`. Play Store art is in `docs/branding/store/`.
