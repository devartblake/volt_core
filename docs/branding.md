# Branding

Volt Core uses logo **B. Core Ring**: a navy disc, a grey ring, a white core and
a navy lightning bolt. Its colours are the app's colour theme, with an
alternate set for dark mode. The single source of truth is
`lib/core/theme/brand_palette.dart`.

## The logo

| Variant | File (`assets/brand/`) | Use on |
|---|---|---|
| Light | `logo-core-ring-light.svg` / `.png` | light surfaces (navy disc, grey ring, white core, navy bolt) |
| Dark | `logo-core-ring-dark.svg` / `.png` | dark or navy surfaces (pale disc, grey ring, deep-navy core, white bolt) |
| Footer | `logo-core-ring-footer.svg` / `.png` | not used (PDFs use the company logo instead, see below) |

In Flutter use the widget, not the files: `AppLogo(size: 40)` picks the light
or dark variant from the theme; `AppLogo.onBrand(size: 120)` always uses the
pale variant for a navy surface (login screen). It is drawn with a
`CustomPainter` from the same palette, so it is crisp at any size and always
matches the files. Pass `decorative: true` to hide it from screen readers when
it sits next to the app name; otherwise it announces "Volt Core logo".

Rules:

- Minimum size 24 px.
- Clear space around the logo = 1/8 of its width on every side.
- Do not recolour, stretch, rotate, outline, or add shadows or effects.
- Use the variant that matches the surface; never put the light variant on navy.

Earlier concepts (A bolt tile, C V layers, D pulse hex) are kept in
`docs/branding/logo-concepts/` for reference only.

Status colours (success, warning, info in `status_colors.dart`, danger =
`colorScheme.error`) are separate from the brand and unchanged.

Where the roles show up: the app bar is navy with white content in light mode
and the navy container with pale content in dark mode; filled buttons, FAB,
selected rail/tab items and stat-card accents use `primary`; selected chips
and nav indicators use the navy-tinted containers. The login screen keeps a
fixed dark palette (`LoginPalette`) built from deep navy and brand navy.
The signature pad is deliberately theme-independent (`SignaturePalette`).
